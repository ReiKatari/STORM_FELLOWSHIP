## ⚡ О проекте

**STORM FELLOWSHIP v0.0.6** — это передовой клиент для командного, игрового и персонального общения, разработанный на базе высокопроизводительного рантайма **.NET 8 LTS** с современным интерфейсом **Fluent XAML**.

### 🌟 Ключевые возможности версии 0.0.6:
1. 🎮 **Игровой оверлей (DirectX 11/12 / Vulkan)**:
   - Полупрозрачный компактный оверлей поверх игр с живыми неоновыми индикаторами говорящих тиммейтов.
   - Быстрый чат и горячие клавиши управления (`Shift + ~`).
2. 🔒 **P2P + E2EE сквозное шифрование**:
   - Сквозное шифрование AES-256-GCM + ECDH Curve25519 для голосовых и текстовых потоков.
   - Проверка отпечатков безопасности (Safety Numbers) в окне звонка и чата.
3. 🔊 **Индивидуальный микшер громкости участников**:
   - Регулировка громкости каждого участника (0–200%) по правому клику.
   - Функции «Заглушить для меня» и «Приоритетный голос» (Priority Speaker).
4. 🤖 **AI Шумоподавление нового поколения (RNNoise / DeepFilterNet)**:
   - Нейросетевое подавление щелчков механической клавиатуры, дыхания и шума окружения в реальном времени.
5. 🖥️ **Трансляция экрана со звуком приложений (WASAPI Loopback Capture)**:
   - Захват чистого звука выбранной игры без звуков системы (1080p/4K 60/120 FPS).
6. 👑 **Система ролей и прав содружеств (RBAC)**:
   - Создание, переименование ролей, настройка прав (Администратор, Модератор, Оратор и др.) и цветные плашки ролей.
7. 🤖 **Whisper AI расшифровка голосовых сообщений**:
   - Локальная транскрипция аудиосообщений в текст в 1 клик с таймкодами.
8. 📁 **Мультисерверные папки**:
   - Группировка содружеств в сворачиваемые папки с кастомными цветами.
9. 🌐 **Позиционный пространственный 3D-звук (Spatial Audio)**:
   - Пространственное позиционирование участников с виртуальным 3D-радаром.
10. 📊 **Интерактивные опросы и голосования (Polls)**:
    - Создание опросов в чате с выбором вариантов, живыми графиками и подсчетом процентов.
11. 🔍 **Мгновенный локальный поиск (SQLite FTS5)**:
    - Полнотекстовый поиск по всем сообщениям, файлам, авторам и датам (`Ctrl + F`).
12. ⚡ **Режим экономии ресурсов (Lite Mode)**:
    - Оптимизированный профиль для слабых ПК и ноутбуков.
13. 🎙️ **Временные голосовые каналы (Voice Hubs)**:
    - Автоматическое создание персональных комнат при подключении к «Хабу» и их авто-удаление.

## 📦 Встроенные программы и библиотеки (Zero-Dependency)

В сборку и установщик программы **нативно встроены все необходимые рантаймы и зависимости**:
- Нативные библиотеки **Microsoft Visual C++ 2015–2026 (x64)** (`msvcp140.dll`, `vcruntime140.dll`, `concrt140.dll` и др.) для портативной работы без предварительной установки.
- Автоматический установщик **VC++ Redistributable** (`vc_redist.x64.exe`).
- Автоматический установщик **Microsoft Edge WebView2 Runtime** (`MicrosoftEdgeWebview2Setup.exe`).
- Автономный пакет **.NET 8 LTS (Self-Contained)**.

## 🛠️ Установка и запуск

### Вариант 1: Быстрая установка через установщик
Запустите `Run_Setup.cmd` или `STORM_FELLOWSHIP_0.0.6_setup.exe` из папки `Files`, либо выполните команду в PowerShell:
```powershell
powershell -ExecutionPolicy Bypass -File "E:\STORM FELLOWSHIP\Files\Install.ps1"
```

### Вариант 2: Портативный запуск без установки
Запустите `Run_STORM_FELLOWSHIP.cmd` в корневой папке или напрямую `StormFellowship.exe` из папки `E:\STORM FELLOWSHIP\Assembling\`.
